KaamMilega Custom Promotional Banner

This version adds a branded KaamMilega promotional banner to:
1. The Google sign-in gate (below Continue with Google).
2. The main homepage (below the hero section).

No Google AdSense or third-party ad network is needed for these self-promotional banners. They are ordinary responsive website sections and do not display third-party paid advertisements.

Deployment:
- Back up your current deployed index.html first.
- Upload this index.html to the same location as your existing homepage (for example, replace the deployed root index.html).
- Keep your existing Supabase and payment configuration as-is; this file is based on the saved KaamMilega page and does not intentionally change its existing features.
- After deployment, hard-refresh/reopen the site.

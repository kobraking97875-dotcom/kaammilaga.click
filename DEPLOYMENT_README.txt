KaamMilega website deployment files

1. Upload KaamMilega_index_fixed.html as index.html
2. Upload privacy-policy.html
3. Upload ads.txt to the website root
4. The Privacy Policy link in index.html points to /privacy-policy.html

Important:
- ads.txt line uses the AdMob publisher ID already configured for KaamMilega.
- If your Google AdSense account shows a different publisher ID, use the AdSense publisher ID for website ads.txt instead.
